# Aai Mother & Child Care Hospital — Final Premium Website

Static production-ready demo built with HTML, CSS and JavaScript.

## Included
- Premium responsive header and services mega menu
- Sky-blue healthcare theme
- Real hospital photos
- Professional Lucide SVG icons instead of emojis
- Compact official-style floating WhatsApp button
- Balanced image gallery with no empty cells
- Appointment form that opens a pre-filled WhatsApp message
- Compact Google Map section
- Local SEO metadata and Hospital JSON-LD schema
- Mobile navigation, scroll reveal and active navigation state

## Files
- `index.html`
- `style.css`
- `script.js`
- `assets/icons/`
- `assets/images/`

## Before publishing for the hospital
1. Confirm hospital logo usage and image permissions.
2. Verify doctor qualification, services, opening hours and facilities.
3. Replace demo review summaries with approved patient testimonials.
4. Replace any placeholder domain in deployment settings.
5. Test phone, WhatsApp and Google Maps links on a real phone.

## Deployment
Upload the folder to GitHub Pages, Netlify or Vercel as a static project. No build command is required.
